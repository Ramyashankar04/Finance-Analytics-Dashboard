 Finance Analytics Dashboard

Project Overview
An interactive Power BI dashboard designed to analyze financial transactions and monitor business performance.

 Tools Used
- Microsoft Power BI
- Microsoft Excel
- Power Query

 Key Features
- Monthly transaction analysis
- Successful vs. failed transaction analysis
- Customer segment analysis
- State-wise financial performance
- Transaction type analysis
- Gender-based analysis
- Year-over-Year (YoY) comparison

Project Objective
To provide meaningful insights into financial transactions and help monitor business performance through interactive visualizations.
